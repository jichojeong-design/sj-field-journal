Google Drive 연동 설정
전체 전송 한 번으로 SJ 현장일지 파일의 오늘일지·날씨기록·일지달력·그래프를 취합합니다. 전송된 원본과 수정 이력은 함께 보관합니다.
URL과 키는 이 브라우저에 보관됩니다. 연결 확인은 일지를 보내지 않고 진행합니다. 자동 전송은 별도로 켜 주세요.
처음 한 번 연결하는 방법
  1. Google Sheets를 새로 만들고 확장 프로그램 → Apps Script를 엽니다. 또는 독립 Apps Script 프로젝트를 사용해도 됩니다.
  2. google_apps_script.js 전체 내용을 붙여넣고 저장합니다.
  3. SJ현장일지생성 함수를 실행하고 권한을 승인합니다. 네 개 탭이 즉시 생성됩니다. 연결 키는 프로젝트 설정 → 스크립트 속성 → SJ_KEY에서 복사합니다.
  4. 배포 → 새 배포 → 웹 앱. 실행 사용자: 나 / 액세스: 모든 사용자로 설정합니다. 연결 키가 일지 전송을 보호하며 시트 자체를 공개하지 않습니다.
  5. 배포된 /exec URL과 연결 키를 위에 입력하고 연결 확인 → 설정 저장을 누릅니다.
전체 전송은 기기의 모든 저장 일지·날씨 조회 이력을 보내고, 기존 클라우드 원본과 취합해 4개 탭과 차트를 갱신합니다. 시트의 내용을 앱으로 가져오는 기능은 아직 지원하지 않습니다.

  
갤럭시 음성 점검
S24 FE 등 갤럭시의 Chrome 기준입니다. 지원 표시만으로 음성 서버 연결 성공을 뜻하지 않습니다.
파일 주소(file/content)나 카카오톡 내부에서 실패하면 HTTPS 웹앱을 Chrome에서 열어야 할 수 있습니다. 입력칸을 눌러 키보드로 직접 입력하는 기능은 계속 사용할 수 있습니다.
